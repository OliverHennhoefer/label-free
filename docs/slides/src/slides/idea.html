With normal data only, a metric brings either its own reference or its own assumption.

Reference points

Points outside the data should score above held-out normal data.

Refits

A good detector ranks the same way every time.

Several detectors

Good detectors agree with each other.

Top scores

Top-scored points are anomalies. Special case: contaminated data.

Four sources of evidence, ordered by how well they fit the normal-only premise. The first three need no anomalies in the data. The last assumes the data are contaminated, so that the top-scored points can be real anomalies; on clean data those points are ordinary boundary points.

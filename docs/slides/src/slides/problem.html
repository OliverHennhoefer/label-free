Evaluation needs anomalies. Normal data has none.

Test data with labelled anomalies (blue): ROC AUC 0.97, AP 0.94

Normal data only: every point is normal, and there is nothing to rank it against

ROC AUC and AP ask whether anomalies outrank normal points. With only normal data there are no anomalies in the ranking at all, labelled or not. A label-free metric has to supply the missing side of the comparison, or avoid needing it.

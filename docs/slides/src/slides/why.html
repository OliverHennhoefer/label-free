Why they fail

No anomalies

Normal data cannot show what a detector misses.

Wrong proxy

Uniform or generated points are not real anomalies.

Self-grading

Top-score metrics reward confidence, not correctness.

Incomparable scores

Different detectors score on different scales.

Correlated pool

Consensus recovers what a default already gives.

Normal data only constrain how a detector treats normal points. Reference and generated points stand in for anomalies but need not resemble them. Metrics that read the top scores grade the detector against its own output. Raw scores from different detector types are not on a common scale. Consensus can only recover the majority view of the pool.

Stability

Do the same points stay on top when the detector is refitted?

Rank of six points across five refits. Left: stable. Right: unstable.

IdeaA ranking that changes with every refit is noise. Refit on subsamples and track each point’s rank.

MetricRanking stability (Perini et al. 2020).

Fails whenA detector that is consistently wrong is perfectly stable. Robustness, not accuracy.

Refit the same detector on random subsamples and track each point’s rank. If the top changes with every refit, a single run is close to noise. Stability can rule detectors out but cannot confirm a good one.

In practice

Baseline

Compare against a strong default, not against random.

Sanity check

A metric must rank a random scorer last.

Scope

Most reliable for tuning within one detector type.

Combine

Aggregate metrics with different assumptions.

Labels

A few confirmed anomalies beat any internal metric.

The metrics narrow choices and catch broken detectors. Rankings from several metrics can be merged by Borda counting; Goswami et al. drop the most influential metrics first. Use labels for the final decision whenever any exist.

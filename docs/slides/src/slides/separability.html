Separability

Special case: contaminated data

How easily can a classifier separate each flagged point from the rest?

Outlier (blue) and inlier (circled)

Separability as the kernel narrows. Outliers separate early.

IdeaA true outlier can be fenced off from the rest with a simple boundary. An inlier cannot.

MetricIREOS (Marques et al. 2020): area under the separability curve, weighted by score, adjusted for chance.

Fails whenCost. One kernel classifier per point and kernel width.

IREOS (Marques et al.) trains a kernel classifier to separate each point from all others, over a range of kernel widths. A true outlier is separable almost immediately; an inlier only when the kernel is so narrow that every point is. The index is the score-weighted area under these curves, adjusted so a random solution scores zero.

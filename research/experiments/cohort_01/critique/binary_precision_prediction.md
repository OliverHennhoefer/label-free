# Predicted behavior of a finite-sample AP certificate

**Frozen 2026-11-22 before simulated draws.** Use the three fixed binary candidates and known operationally ordered two-cohort world in [the population derivation](ordered_mixtures.md). One detector flags the first cell (A), one flags the second (B), and one flags either (C). Sampling is independent within and between cohorts. Freeze the alert sets before collecting either sample. The target outcome is non-interpolated population AP. Both cohorts share the normal and anomaly laws. No single-batch benchmark inputs are used.

For $m=3$ alert sets construct two-sided Clopper–Pearson intervals for each of the $2m$ marginal alert probabilities, spending $0.05/(2m)$ per interval. Form simultaneous intervals by ordinary interval arithmetic for $D=H(E)-T(E)$, $Q=D^2/T(E)$ and $D+Q$. If a target interval touches zero, set the upper bound on $Q$ to infinity. Across a candidate pair, certify the first has higher AP only when both its lower $Q$ bound and its lower $D+Q$ bound strictly exceed the corresponding upper bounds of the second. Otherwise abstain, testing both orientations. This is sufficient for every $b\ge1$, independent of joint-cell support estimates.

Use $T=(.05,.50,.45)$, $H=(.055,.510,.435)$ as given and 4,096 independent pairs of multinomial sample counts at each equal cohort size of $10^4,10^6,10^7$. NumPy `SeedSequence(310071).spawn(3)` assigns a distinct deterministic stream to each size. Evaluate each size separately. The exact population values put C above B for every $b\ge1$, while A–B changes order inside the identified set. C–A changes order outside the feasible set, so this deliberately conservative test can miss its identifiable order.

**Predictions.** C–B coverage at $10^7$ exceeds 95% and is higher than at $10^4$, where I expect mostly abstentions. The middle size probes the transition. A–B should usually be unresolved. Count every A–B certificate as incompatible with some feasible world, even when it happens to match the generating prevalence. Also report false directional certificates over all three pairs, C–A coverage, and how the empirical failure rate compares with the simultaneous 5% guarantee. Sample size, error rate, seeds, repetitions, intervals and cutoffs are fixed for this experiment.
